# Класс `EvaluationDetails`

Подробный результат оценки флага. Возвращается методами вида `ПолучитьЛогическоеСДеталями`.

Всегда содержит значение: при ошибке это значение по умолчанию, а причина отказа описана полями `КодОшибки`
и `СообщениеОбОшибке`.

Спецификация: [Evaluation details](https://openfeature.dev/specification/types#evaluation-details).

## Конструктор

```bsl
Новый EvaluationDetails(Знач Ключ = "", Знач ЗначениеФлага = Неопределено)
```

| Параметр | Тип | Описание |
|---|---|---|
| `Ключ` | `Строка` | Ключ флага |
| `ЗначениеФлага` | `Произвольный` | Начальное значение, обычно значение по умолчанию |

Объект создаёт клиент; прикладной код получает его готовым.

## Свойства

| Свойство | Тип | Описание |
|---|---|---|
| `КлючФлага` | `Строка` | Ключ оценённого флага |
| `Значение` | `Произвольный` | Значение флага либо значение по умолчанию при ошибке |
| `Вариант` | `Строка` | Идентификатор варианта, если провайдер его различает |
| `Причина` | `Строка` | Причина, по которой получено значение, см. [`OpenFeatureReason`](../Модули/OpenFeatureReason.md) |
| `КодОшибки` | `Строка` | Код ошибки, см. [`OpenFeatureErrorCode`](../Модули/OpenFeatureErrorCode.md). Пустая строка при успехе |
| `СообщениеОбОшибке` | `Строка` | Пояснение к ошибке |
| `МетаданныеФлага` | `Соответствие` | Метаданные флага, переданные провайдером |

Метаданные при отсутствии данных - пустая запись, а не `Неопределено`: так требует спецификация, и прикладному коду
не нужна проверка на `Неопределено`.

## Методы

| Метод | Возвращает | Назначение |
|---|---|---|
| [`ЭтоОшибка`](#этоошибка) | `Булево` | Завершилась ли оценка ошибкой |
| [`Метаданное`](#метаданное) | `Произвольный` | Значение метаданного флага |
| [`ЗаполнитьИзРезультата`](#заполнитьизрезультата) | - | Перенос данных из результата провайдера |

## ЭтоОшибка

```bsl
Функция ЭтоОшибка() Экспорт
```

**Возвращаемое значение**: `Булево` - `Истина`, если оценка завершилась ошибкой, то есть заполнен `КодОшибки`.

Причина `DISABLED` ошибкой не является: выключенный флаг - это нормальный результат.

```bsl
Детали = Клиент.ПолучитьЛогическоеСДеталями("new-checkout", Ложь);

Если Детали.ЭтоОшибка() Тогда
	Журнал.Предупреждение(Детали.КодОшибки + ": " + Детали.СообщениеОбОшибке);
КонецЕсли;
```

## Метаданное

```bsl
Функция Метаданное(Знач Имя, Знач ЗначениеПоУмолчанию = Неопределено) Экспорт
```

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Имя` | `Строка` | Имя метаданного |
| `ЗначениеПоУмолчанию` | `Произвольный` | Результат, если метаданного нет |

**Возвращаемое значение**: `Произвольный` - значение метаданного.

```bsl
Сообщить(Детали.Метаданное("эксперимент", "нет"));
```

## ЗаполнитьИзРезультата

```bsl
Процедура ЗаполнитьИзРезультата(Знач Результат) Экспорт
```

Заполняет детали из результата провайдера: значение, вариант, причину, код и сообщение об ошибке, метаданные. Метод
нужен клиенту; прикладной код его не вызывает.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Результат` | [`ResolutionDetails`](ResolutionDetails.md) | Результат разрешения флага |
