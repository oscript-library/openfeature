# Класс `InMemoryProvider`

Провайдер флагов, хранящий конфигурацию в памяти. Основной сценарий - тесты и локальная разработка: набор флагов
задаётся прямо в коде и меняется на лету.

```bsl
Флаги = Новый Соответствие();
Флаги.Вставить("new-checkout", Истина);

OpenFeature.УстановитьПровайдер(Новый InMemoryProvider(Флаги));
```

Ключи флагов часто содержат дефисы, поэтому набор задают `Соответствием`: имя свойства структуры так выглядеть
не может.

## Конструктор

```bsl
Новый InMemoryProvider(Знач НачальныеФлаги = Неопределено)
```

| Параметр | Тип | Описание |
|---|---|---|
| `НачальныеФлаги` | `Структура`, `Соответствие` | Описание флагов |

## Описание флага

Флаг описывается либо значением, либо развёрнутой структурой:

```bsl
Флаги.Вставить("new-checkout", Истина);           // простой флаг
Флаги.Вставить("тема", РазвёрнутоеОписание);       // варианты и правила
```

Поля развёрнутого описания:

| Поле | Тип | Описание |
|---|---|---|
| `Значение` | `Произвольный` | Значение флага, если вариантов нет |
| `Варианты` | `Структура`, `Соответствие` | Имя варианта -> значение |
| `ВариантПоУмолчанию` | `Строка` | Имя варианта, который возвращается без совпадения правил |
| `Включен` | `Булево` | `Ложь` - флаг всегда отдаёт значение по умолчанию с причиной `DISABLED` |
| `Правила` | `Массив` | Правила таргетинга |

Правило - структура с полями:

| Поле | Тип | Описание |
|---|---|---|
| `Атрибут` | `Строка` | Имя атрибута контекста, в том числе `targetingKey` |
| `Значения` | `Массив` | Значения, при которых правило срабатывает |
| `Вариант` | `Строка` | Имя варианта, который возвращается при совпадении |

Правила проверяются по порядку, побеждает первое совпавшее. Совпадение даёт причину `TARGETING_MATCH`, вариант
по умолчанию - `STATIC`. Значения сравниваются как строки.

```bsl
Варианты = Новый Соответствие();
Варианты.Вставить("светлая", "light");
Варианты.Вставить("тёмная", "dark");

Значения = Новый Массив();
Значения.Добавить("pro");

Правила = Новый Массив();
Правила.Добавить(Новый Структура("Атрибут,Значения,Вариант", "plan", Значения, "тёмная"));

Тема = Новый Структура();
Тема.Вставить("Варианты", Варианты);
Тема.Вставить("ВариантПоУмолчанию", "светлая");
Тема.Вставить("Правила", Правила);
```

Ошибки в описании дают код `PARSE_ERROR`: не задан вариант по умолчанию, вариант не описан среди вариантов.

## Контракт провайдера

| Метод | Возвращает | Описание |
|---|---|---|
| `Метаданные()` | `Структура` | `Имя` = `InMemoryProvider` |
| `Инициализировать(Контекст = Неопределено)` | - | Переводит провайдера в `READY` |
| `Завершить()` | - | Переводит провайдера в `NOT_READY` |
| `Состояние()` | `Строка` | `NOT_READY` или `READY` |
| `ВычислитьЛогическое(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Оценка `Булево` |
| `ВычислитьСтроку(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Оценка `Строка` |
| `ВычислитьЧисло(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Оценка `Число` |
| `ВычислитьОбъект(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Оценка без проверки типа |

`Инициализировать` вызывает [`УстановитьПровайдер`](../Модули/OpenFeature.md#установитьпровайдер), поэтому вручную его
дёргать не нужно. До инициализации оценка возвращает код `PROVIDER_NOT_READY`.

## Управление набором флагов

| Метод | Возвращает | Назначение |
|---|---|---|
| [`ЗаменитьФлаги`](#заменитьфлаги) | - | Замена всего набора |
| [`УстановитьФлаг`](#установитьфлаг) | - | Добавление или замена одного флага |
| [`УдалитьФлаг`](#удалитьфлаг) | - | Удаление флага |
| [`Флаги`](#флаги) | `Соответствие` | Копия текущего набора |

## ЗаменитьФлаги

```bsl
Процедура ЗаменитьФлаги(Знач НовыеФлаги) Экспорт
```

Заменяет весь набор флагов. Прежний набор отбрасывается целиком.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `НовыеФлаги` | `Структура`, `Соответствие` | Описание флагов |

```bsl
Провайдер.ЗаменитьФлаги(ПрочитатьНастройкиТеста());
```

## УстановитьФлаг

```bsl
Процедура УстановитьФлаг(Знач Ключ, Знач Описание) Экспорт
```

Добавляет или заменяет один флаг.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Ключ` | `Строка` | Ключ флага |
| `Описание` | `Произвольный` | Значение либо развёрнутое описание флага |

```bsl
Провайдер.УстановитьФлаг("new-checkout", Ложь);
```

## УдалитьФлаг

```bsl
Процедура УдалитьФлаг(Знач Ключ) Экспорт
```

Удаляет флаг. Дальнейшая оценка вернёт значение по умолчанию с кодом `FLAG_NOT_FOUND`.

**Параметры**: `Ключ` - `Строка` ключ флага.

```bsl
Провайдер.УдалитьФлаг("экспериментальный-поиск");
```

## Флаги

```bsl
Функция Флаги() Экспорт
```

**Возвращаемое значение**: `Соответствие` - копия текущего набора флагов. Изменение копии на провайдера не влияет.

```bsl
Сообщить(Провайдер.Флаги().Количество());
```
