# Класс `OpenFeatureApi`

Изолированный экземпляр OpenFeature API. Хранит провайдера, глобальные хуки и глобальный контекст оценки.

Модуль [`OpenFeature`](../Модули/OpenFeature.md) - это глобальный экземпляр реестра, и его методы просто переадресуются
сюда. Отдельные экземпляры нужны там, где глобальное состояние мешает: прежде всего в тестах и когда в одном процессе
живут несколько несвязанных приложений.

```bsl
Экземпляр = OpenFeature.СоздатьИзолированныйЭкземпляр();
// то же самое напрямую
Экземпляр = Новый OpenFeatureApi();
```

## Конструктор

```bsl
Новый OpenFeatureApi()
```

Параметров нет. Новый экземпляр сразу получает [`NoopProvider`](NoopProvider.md), пустой список хуков и пустой
контекст оценки.

## Методы

Набор совпадает с модулем `OpenFeature` и дополнен двумя методами, которые нужны клиенту.

| Метод | Возвращает | Назначение |
|---|---|---|
| `УстановитьПровайдер(Провайдер)` | - | Регистрация провайдера |
| `Провайдер()` | `Произвольный` | Текущий провайдер |
| `МетаданныеПровайдера()` | `Структура` | Метаданные провайдера |
| `СостояниеПровайдера()` | `Строка` | Состояние провайдера |
| `ПолучитьКлиента(Домен = "")` | [`FeatureClient`](FeatureClient.md) | Клиент оценки |
| `ДобавитьХук(Хук)` | - | Хук для всех клиентов экземпляра |
| [`ГлобальныеХуки`](#глобальныехуки) | `Массив` | Зарегистрированные хуки |
| `УстановитьГлобальныйКонтекст(Контекст)` | - | Контекст уровня приложения |
| `ГлобальныйКонтекст()` | [`EvaluationContext`](EvaluationContext.md) | Текущий глобальный контекст |
| `Завершить()` | - | Сброс состояния экземпляра |
| [`ЕстьМетод`](#естьметод) | `Булево` | Проверка наличия метода у объекта |

Описание совпадающих методов приведено в [модуле `OpenFeature`](../Модули/OpenFeature.md).

```bsl
Экземпляр = OpenFeature.СоздатьИзолированныйЭкземпляр();
Экземпляр.УстановитьПровайдер(Новый InMemoryProvider(Флаги));

Клиент = Экземпляр.ПолучитьКлиента("тест");

Ожидаем.Что(Клиент.ПолучитьЛогическое("new-checkout", Ложь)).ЭтоИстина();
```

## ГлобальныеХуки

```bsl
Функция ГлобальныеХуки() Экспорт
```

**Возвращаемое значение**: `Массив` - зарегистрированные глобальные хуки в порядке добавления. Метод нужен клиенту:
он собирает хуки трёх уровней перед оценкой.

## ЕстьМетод

```bsl
Функция ЕстьМетод(Знач Объект, Знач ИмяМетода) Экспорт
```

Проверяет наличие метода у объекта. Результат кэшируется по типу: разбор состава методов заметно дороже самой оценки
флага. Метод нужен клиенту, чтобы вызывать у хука только те стадии, которые он реализует.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Объект` | `Произвольный` | Проверяемый объект |
| `ИмяМетода` | `Строка` | Имя искомого метода |

**Возвращаемое значение**: `Булево` - `Истина`, если метод есть. Если состав методов объекта недоступен, возвращается
`Истина`: безопаснее попытаться вызвать.

## Завершение экземпляра

`Завершить()` завершает провайдера и сбрасывает хуки, контекст и кэш методов, после чего снова ставит заглушку.
В тестах это удобно в блоке после каждого теста, хотя изолированный экземпляр можно просто выбросить.

```bsl
&ПослеКаждого
Процедура ОсвободитьAPI() Экспорт

	Экземпляр.Завершить();

КонецПроцедуры
```
