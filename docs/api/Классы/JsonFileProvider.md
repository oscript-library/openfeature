# Класс `JsonFileProvider`

Провайдер флагов, читающий конфигурацию из JSON-файла. Файл перечитывается при инициализации и по явному вызову
`Перечитать`, поэтому флаги обновляются без перезапуска приложения.

Разбор описания флагов и таргетинг выполняет [`InMemoryProvider`](InMemoryProvider.md): формат файла тот же, что
понимает он.

```bsl
OpenFeature.УстановитьПровайдер(Новый JsonFileProvider("флаги.json"));
```

## Конструктор

```bsl
Новый JsonFileProvider(Знач Путь)
```

| Параметр | Тип | Описание |
|---|---|---|
| `Путь` | `Строка` | Путь к JSON-файлу с описанием флагов |

Пустой путь или значение не строкового типа дают исключение: это ошибка настройки приложения, а не внештатная
ситуация во время работы.

## Формат файла

```json
{
  "new-checkout": true,
  "максимум-позиций": 20,
  "тема": {
    "Варианты": { "светлая": "light", "тёмная": "dark" },
    "ВариантПоУмолчанию": "светлая",
    "Правила": [
      { "Атрибут": "plan", "Значения": ["pro"], "Вариант": "тёмная" }
    ]
  },
  "экспериментальный-поиск": {
    "Значение": "быстрый",
    "Включен": false
  }
}
```

Корень файла должен быть объектом JSON. Полное описание полей - в [`InMemoryProvider`](InMemoryProvider.md#описание-флага).

## Контракт провайдера

| Метод | Возвращает | Описание |
|---|---|---|
| `Метаданные()` | `Структура` | `Имя` = `JsonFileProvider` |
| `Инициализировать(Контекст = Неопределено)` | - | Читает файл |
| `Завершить()` | - | Переводит провайдера в `NOT_READY` |
| `Состояние()` | `Строка` | `NOT_READY`, `READY` или `ERROR` |
| `ВычислитьЛогическое(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Оценка `Булево` |
| `ВычислитьСтроку(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Оценка `Строка` |
| `ВычислитьЧисло(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Оценка `Число` |
| `ВычислитьОбъект(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Оценка без проверки типа |

Пока провайдер в `ERROR`, оценка возвращает значение по умолчанию с кодом `PARSE_ERROR` и текстом последней ошибки
чтения. В состоянии `NOT_READY` код будет `PROVIDER_NOT_READY`.

## Методы

| Метод | Возвращает | Назначение |
|---|---|---|
| [`Перечитать`](#перечитать) | `Булево` | Повторное чтение файла |
| [`ПоследняяОшибка`](#последняяошибка) | `Строка` | Описание последней ошибки чтения |
| [`Флаги`](#флаги) | `Соответствие` | Текущий набор флагов |

## Перечитать

```bsl
Функция Перечитать() Экспорт
```

Перечитывает файл. Ошибка чтения переводит провайдера в состояние `ERROR`, но **не выбрасывает исключение**:
приложение продолжает работать на значениях по умолчанию, а не падает из-за испорченного конфига.

Причины неудачи: файла нет, файл не читается, содержимое не является объектом JSON.

**Возвращаемое значение**: `Булево` - `Истина`, если файл прочитан успешно.

```bsl
// например по расписанию или по сигналу
Если Не Провайдер.Перечитать() Тогда
	Журнал.Предупреждение(Провайдер.ПоследняяОшибка());
КонецЕсли;
```

## ПоследняяОшибка

```bsl
Функция ПоследняяОшибка() Экспорт
```

**Возвращаемое значение**: `Строка` - описание последней ошибки чтения файла. Пустая строка после успешного чтения.

```bsl
Сообщить(Провайдер.ПоследняяОшибка());
// Файл флагов C:\app\флаги.json не найден
```

## Флаги

```bsl
Функция Флаги() Экспорт
```

**Возвращаемое значение**: `Соответствие` - текущий набор флагов, прочитанный из файла.

```bsl
Сообщить("Флагов прочитано: " + Провайдер.Флаги().Количество());
```
