# Класс `NoopProvider`

Провайдер, который всегда возвращает значение по умолчанию. Действует, пока настоящий провайдер не зарегистрирован:
приложение, обращающееся к флагам на старте, получает предсказуемые значения по умолчанию, а не ошибку.

Спецификация [Flag Evaluation](https://openfeature.dev/specification/sections/flag-evaluation) прямо этого требует:
«In the absence of a provider the evaluation API uses the No-op provider».

Создавать его вручную обычно не нужно: экземпляр API ставит заглушку сам при создании и при
[`Завершить`](../Модули/OpenFeature.md#завершить).

```bsl
Сообщить(OpenFeature.МетаданныеПровайдера().Имя);  // NoopProvider

Детали = OpenFeature.ПолучитьКлиента().ПолучитьЛогическоеСДеталями("любой-флаг", Истина);

Сообщить(Детали.Значение);  // Да, то есть значение по умолчанию
Сообщить(Детали.Причина);   // DEFAULT
```

## Конструктор

```bsl
Новый NoopProvider()
```

Параметров нет.

## Контракт провайдера

| Метод | Возвращает | Описание |
|---|---|---|
| `Метаданные()` | `Структура` | `Имя` = `NoopProvider` |
| `Инициализировать(Контекст = Неопределено)` | - | Ничего не делает |
| `Завершить()` | - | Ничего не делает |
| `Состояние()` | `Строка` | Всегда `READY` |
| `ВычислитьЛогическое(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Значение по умолчанию, причина `DEFAULT` |
| `ВычислитьСтроку(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Значение по умолчанию, причина `DEFAULT` |
| `ВычислитьЧисло(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Значение по умолчанию, причина `DEFAULT` |
| `ВычислитьОбъект(Ключ, ЗначениеПоУмолчанию, Контекст)` | `ResolutionDetails` | Значение по умолчанию, причина `DEFAULT` |

Состояние `READY` не означает, что флаги доступны: заглушка готова к работе всегда, потому что ей нечего готовить.
Отличить её от настоящего провайдера можно по метаданным.

Причина `DEFAULT` отличает заглушку от ошибки: код ошибки не заполняется, `ЭтоОшибка()` вернёт `Ложь`. Приложение,
запущенное без настроенных флагов, ведёт себя как приложение со всеми флагами в положении по умолчанию.
