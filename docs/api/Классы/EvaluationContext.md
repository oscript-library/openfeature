# Класс `EvaluationContext`

Контекст оценки флага: данные, по которым провайдер принимает решение. Ключ таргетинга выделен отдельно: по нему
провайдеры закрепляют пользователя за вариантом, чтобы процентные выкатки были стабильными.

Спецификация: [Evaluation Context](https://openfeature.dev/specification/sections/evaluation-context).

```bsl
Контекст = Новый EvaluationContext("user-42", Новый Структура("plan,регион", "pro", "RU"));
```

## Конструктор

```bsl
Новый EvaluationContext(Знач КлючТаргетинга = "", Знач НачальныеАтрибуты = Неопределено)
```

| Параметр | Тип | Описание |
|---|---|---|
| `КлючТаргетинга` | `Строка` | Идентификатор субъекта оценки: пользователя, организации, устройства |
| `НачальныеАтрибуты` | `Структура`, `Соответствие` | Произвольные атрибуты |

Ключ таргетинга хранится среди атрибутов под именем `targetingKey`, поэтому правила провайдера могут ссылаться
на него как на обычный атрибут. Пустой ключ не добавляется.

## Методы

| Метод | Возвращает | Назначение |
|---|---|---|
| [`КлючТаргетинга`](#ключтаргетинга) | `Строка` | Значение `targetingKey` |
| [`УстановитьКлючТаргетинга`](#установитьключтаргетинга) | `EvaluationContext` | Замена ключа таргетинга |
| [`Установить`](#установить) | `EvaluationContext` | Добавление атрибута |
| [`Получить`](#получить) | `Произвольный` | Значение атрибута |
| [`Содержит`](#содержит) | `Булево` | Задан ли атрибут |
| [`Атрибуты`](#атрибуты) | `Соответствие` | Копия всех атрибутов |
| [`Объединить`](#объединить) | `EvaluationContext` | Слияние с другим контекстом |
| [`Количество`](#количество) | `Число` | Количество атрибутов |

`УстановитьКлючТаргетинга` и `Установить` возвращают тот же контекст, поэтому вызовы выстраиваются в цепочку.

## КлючТаргетинга

```bsl
Функция КлючТаргетинга() Экспорт
```

**Возвращаемое значение**: `Строка` - значение `targetingKey` либо пустая строка.

```bsl
Сообщить(Контекст.КлючТаргетинга());  // user-42
```

## УстановитьКлючТаргетинга

```bsl
Функция УстановитьКлючТаргетинга(Знач Значение) Экспорт
```

**Параметры**: `Значение` - `Строка` новый ключ таргетинга.

**Возвращаемое значение**: `EvaluationContext` - этот же контекст.

```bsl
Контекст.УстановитьКлючТаргетинга(Пользователь.Идентификатор);
```

## Установить

```bsl
Функция Установить(Знач Имя, Знач Значение) Экспорт
```

Добавляет или заменяет атрибут.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Имя` | `Строка` | Имя атрибута |
| `Значение` | `Произвольный` | Значение атрибута |

**Возвращаемое значение**: `EvaluationContext` - этот же контекст.

```bsl
Контекст = Новый EvaluationContext("user-7")
	.Установить("plan", "pro")
	.Установить("страна", "RU");
```

## Получить

```bsl
Функция Получить(Знач Имя, Знач ЗначениеПоУмолчанию = Неопределено) Экспорт
```

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Имя` | `Строка` | Имя атрибута |
| `ЗначениеПоУмолчанию` | `Произвольный` | Результат, если атрибута нет |

**Возвращаемое значение**: `Произвольный` - значение атрибута.

```bsl
Сообщить(Контекст.Получить("город", "не указан"));
```

## Содержит

```bsl
Функция Содержит(Знач Имя) Экспорт
```

**Параметры**: `Имя` - `Строка` имя атрибута.

**Возвращаемое значение**: `Булево` - `Истина`, если атрибут задан.

```bsl
Если Не Контекст.Содержит("plan") Тогда
	Контекст.Установить("plan", "free");
КонецЕсли;
```

## Атрибуты

```bsl
Функция Атрибуты() Экспорт
```

**Возвращаемое значение**: `Соответствие` - копия всех атрибутов, включая `targetingKey`. Изменение копии не влияет
на контекст.

```bsl
Для Каждого Атрибут Из Контекст.Атрибуты() Цикл
	Сообщить(Атрибут.Ключ + " = " + Атрибут.Значение);
КонецЦикла;
```

## Объединить

```bsl
Функция Объединить(Знач Другой) Экспорт
```

Объединяет контекст с другим. Значения другого контекста имеют приоритет - именно так спецификация предписывает
разрешать конфликты: чем ближе контекст к месту вызова, тем он важнее. Исходные контексты не изменяются.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Другой` | `EvaluationContext` | Контекст с более высоким приоритетом, допускается `Неопределено` |

**Возвращаемое значение**: `EvaluationContext` - новый контекст.

```bsl
Итоговый = ГлобальныйКонтекст.Объединить(КонтекстВызова);
```

Клиент выполняет это объединение сам: глобальный контекст объединяется с контекстом вызова, а затем с тем, что вернул
хук на стадии `До`.

## Количество

```bsl
Функция Количество() Экспорт
```

**Возвращаемое значение**: `Число` - количество атрибутов, включая `targetingKey`.

```bsl
Сообщить(Контекст.Количество());
```
