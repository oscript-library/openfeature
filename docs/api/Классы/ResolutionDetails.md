# Класс `ResolutionDetails`

Результат разрешения флага провайдером. Структуру заполняет автор провайдера; прикладному коду она не видна -
клиент преобразует её в [`EvaluationDetails`](EvaluationDetails.md).

Спецификация: [Resolution details](https://openfeature.dev/specification/types#resolution-details).

## Конструктор

```bsl
Новый ResolutionDetails(Знач ЗначениеФлага = Неопределено, Знач ПричинаОценки = "STATIC",
	Знач ВариантФлага = "")
```

| Параметр | Тип | Описание |
|---|---|---|
| `ЗначениеФлага` | `Произвольный` | Результат разрешения |
| `ПричинаОценки` | `Строка` | Причина, см. [`OpenFeatureReason`](../Модули/OpenFeatureReason.md) |
| `ВариантФлага` | `Строка` | Идентификатор варианта |

```bsl
Возврат Новый ResolutionDetails("dark", OpenFeatureReason.СовпадениеТаргетинга(), "тёмная");
```

## Свойства

| Свойство | Тип | Описание |
|---|---|---|
| `Значение` | `Произвольный` | Значение флага |
| `Вариант` | `Строка` | Идентификатор варианта, если провайдер его различает |
| `Причина` | `Строка` | Причина, по которой получено значение |
| `КодОшибки` | `Строка` | Код ошибки. Пустая строка при успехе |
| `СообщениеОбОшибке` | `Строка` | Пояснение к ошибке |
| `МетаданныеФлага` | `Соответствие` | Произвольные метаданные флага |

## Методы

| Метод | Возвращает | Назначение |
|---|---|---|
| [`ЗаполнитьОшибку`](#заполнитьошибку) | `ResolutionDetails` | Пометка результата как ошибочного |
| [`УстановитьМетаданное`](#установитьметаданное) | `ResolutionDetails` | Добавление метаданного флага |
| [`ЭтоОшибка`](#этоошибка) | `Булево` | Завершилось ли разрешение ошибкой |

Первые два метода возвращают тот же результат, поэтому вызовы выстраиваются в цепочку.

## ЗаполнитьОшибку

```bsl
Функция ЗаполнитьОшибку(Знач Код, Знач Сообщение, Знач ЗначениеПоУмолчанию = Неопределено) Экспорт
```

Помечает результат как ошибочный: заполняет код и сообщение, ставит причину `ERROR`, очищает вариант и подставляет
значение, которое получит вызывающий.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Код` | `Строка` | Код ошибки, см. [`OpenFeatureErrorCode`](../Модули/OpenFeatureErrorCode.md) |
| `Сообщение` | `Строка` | Пояснение |
| `ЗначениеПоУмолчанию` | `Произвольный` | Значение, которое получит вызывающий |

**Возвращаемое значение**: `ResolutionDetails` - этот же результат.

```bsl
Результат = Новый ResolutionDetails(ЗначениеПоУмолчанию);

Возврат Результат.ЗаполнитьОшибку(OpenFeatureErrorCode.ФлагНеНайден(),
	СтрШаблон("Флаг %1 не найден", Ключ), ЗначениеПоУмолчанию);
```

## УстановитьМетаданное

```bsl
Функция УстановитьМетаданное(Знач Имя, Знач ЗначениеМетаданного) Экспорт
```

Добавляет метаданные флага. Они доходят до прикладного кода в `EvaluationDetails.МетаданныеФлага` и годятся, например,
для идентификатора эксперимента.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Имя` | `Строка` | Имя метаданного |
| `ЗначениеМетаданного` | `Строка`, `Число`, `Булево` | Значение метаданного |

**Возвращаемое значение**: `ResolutionDetails` - этот же результат.

```bsl
Возврат Новый ResolutionDetails(Значение, OpenFeatureReason.Распределение(), "вариант-б")
	.УстановитьМетаданное("эксперимент", "checkout-2026");
```

## ЭтоОшибка

```bsl
Функция ЭтоОшибка() Экспорт
```

**Возвращаемое значение**: `Булево` - `Истина`, если разрешение завершилось ошибкой, то есть заполнен `КодОшибки`.

```bsl
Если Разрешённое.ЭтоОшибка() Тогда
	Возврат Разрешённое;
КонецЕсли;
```

## Свой провайдер

Каждый метод оценки провайдера возвращает `ResolutionDetails`:

```bsl
Функция ВычислитьЛогическое(Знач Ключ, Знач ЗначениеПоУмолчанию, Знач Контекст) Экспорт

	Если Не Известен(Ключ) Тогда
		Результат = Новый ResolutionDetails(ЗначениеПоУмолчанию);

		Возврат Результат.ЗаполнитьОшибку(OpenFeatureErrorCode.ФлагНеНайден(),
			"Флаг не найден", ЗначениеПоУмолчанию);
	КонецЕсли;

	Возврат Новый ResolutionDetails(Значение(Ключ), OpenFeatureReason.Статическое());

КонецФункции
```

Клиент дополнительно проверяет тип возвращённого значения, поэтому провайдер может не заботиться о совпадении типа
с методом: несовпадение превратится в `TYPE_MISMATCH`.
