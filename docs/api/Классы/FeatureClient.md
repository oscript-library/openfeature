# Класс `FeatureClient`

Клиент оценки флагов. Создаётся через [`OpenFeature.ПолучитьКлиента`](../Модули/OpenFeature.md#получитьклиента) или
через изолированный экземпляр API.

Главное свойство клиента: **методы оценки никогда не выбрасывают исключений**. Любая внештатная ситуация - недоступный
провайдер, отсутствующий флаг, неверный тип, сбой хука - приводит к возврату значения по умолчанию. Флаги не должны
ронять приложение.

```bsl
Клиент = OpenFeature.ПолучитьКлиента("магазин");
```

Спецификация: [Flag Evaluation](https://openfeature.dev/specification/sections/flag-evaluation).

## Методы оценки

Восемь методов оценки различаются только типом значения и полнотой результата. Сигнатура одинаковая:

```bsl
Функция ПолучитьЛогическое(Знач Ключ, Знач ЗначениеПоУмолчанию, Знач Контекст = Неопределено,
	Знач Параметры = Неопределено) Экспорт
```

| Метод | Тип значения | Возвращает |
|---|---|---|
| `ПолучитьЛогическое` | `Булево` | Значение флага |
| `ПолучитьСтроку` | `Строка` | Значение флага |
| `ПолучитьЧисло` | `Число` | Значение флага |
| `ПолучитьОбъект` | любой | Значение флага |
| `ПолучитьЛогическоеСДеталями` | `Булево` | [`EvaluationDetails`](EvaluationDetails.md) |
| `ПолучитьСтрокуСДеталями` | `Строка` | [`EvaluationDetails`](EvaluationDetails.md) |
| `ПолучитьЧислоСДеталями` | `Число` | [`EvaluationDetails`](EvaluationDetails.md) |
| `ПолучитьОбъектСДеталями` | любой | [`EvaluationDetails`](EvaluationDetails.md) |

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Ключ` | `Строка` | Ключ флага |
| `ЗначениеПоУмолчанию` | по типу метода | Значение при любой внештатной ситуации |
| `Контекст` | [`EvaluationContext`](EvaluationContext.md) | Контекст вызова |
| `Параметры` | `Структура`, `Соответствие` | Хуки и подсказки для этой оценки |

Поля `Параметры`:

| Поле | Тип | Описание |
|---|---|---|
| `Хуки` | `Массив` | Хуки только для этой оценки |
| `ПодсказкиХуков` | `Соответствие` | Произвольные данные, доступные хукам |

Методы без деталей - это те же методы с деталями, у которых взято поле `Значение`. Разницы в стоимости нет: выбор
между ними определяется тем, нужна ли причина.

```bsl
Если Клиент.ПолучитьЛогическое("new-checkout", Ложь, Контекст) Тогда
	ПоказатьНовуюКорзину();
КонецЕсли;

Детали = Клиент.ПолучитьСтрокуСДеталями("тема", "light", Контекст);

Сообщить(Детали.Значение);   // dark
Сообщить(Детали.Вариант);    // тёмная
Сообщить(Детали.Причина);    // TARGETING_MATCH
```

`ПолучитьОбъект` не проверяет тип: провайдер вправе вернуть любую структуру данных. Остальные три метода при
несовпадении типа возвращают значение по умолчанию с кодом `TYPE_MISMATCH`, а не приводят типы молча.

## Метаданные и настройка

| Метод | Возвращает | Назначение |
|---|---|---|
| [`Метаданные`](#метаданные) | `Структура` | Метаданные клиента |
| [`ДобавитьХук`](#добавитьхук) | - | Хук для оценок этого клиента |
| [`СостояниеПровайдера`](#состояниепровайдера) | `Строка` | Состояние связанного провайдера |

## Метаданные

```bsl
Функция Метаданные() Экспорт
```

**Возвращаемое значение**: `Структура` - метаданные клиента с полем `Домен`. Те же метаданные приходят хукам в поле
`МетаданныеКлиента`.

```bsl
Сообщить(Клиент.Метаданные().Домен);  // магазин
```

## ДобавитьХук

```bsl
Процедура ДобавитьХук(Знач Хук) Экспорт
```

Добавляет хук, выполняемый при каждой оценке этого клиента. Хуки клиента выполняются после хуков уровня API и до
хуков отдельного вызова.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Хук` | `Произвольный` | Объект с методами `До`, `После`, `ПриОшибке`, `Финально` (любой из них может отсутствовать) |

```bsl
Клиент.ДобавитьХук(Новый ХукАудита());
```

## СостояниеПровайдера

```bsl
Функция СостояниеПровайдера() Экспорт
```

**Возвращаемое значение**: `Строка` - состояние связанного провайдера: `NOT_READY`, `READY`, `ERROR`, `STALE`
или `FATAL`.

```bsl
Если Клиент.СостояниеПровайдера() = "ERROR" Тогда
	Журнал.Предупреждение("Флаги недоступны, работаем на значениях по умолчанию");
КонецЕсли;
```
