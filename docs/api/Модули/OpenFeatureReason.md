# Модуль `OpenFeatureReason`

Причины, по которым получено значение флага. Модуль даёт константы вместо строковых литералов: опечатка в имени
функции видна сразу, опечатка в строке - только на проде.

Спецификация: [Resolution reason](https://openfeature.dev/specification/types#resolution-reason).

Список не закрыт: провайдер может вернуть любую строку, если ни одна из перечисленных причин не описывает ситуацию
точно.

## Функции

Каждая функция возвращает `Строка` и не принимает параметров.

| Функция | Значение | Когда провайдер её возвращает |
|---|---|---|
| `Статическое()` | `STATIC` | Значение статично, динамическая оценка не выполнялась |
| `ПоУмолчанию()` | `DEFAULT` | Динамическая оценка не выполнялась либо не дала результата |
| `СовпадениеТаргетинга()` | `TARGETING_MATCH` | Значение получено по правилу таргетинга |
| `Распределение()` | `SPLIT` | Значение получено псевдослучайным распределением, например процентной выкаткой |
| `ИзКэша()` | `CACHED` | Значение взято из кэша |
| `Выключено()` | `DISABLED` | Флаг выключен в системе управления |
| `Неизвестно()` | `UNKNOWN` | Причину определить не удалось |
| `Устарело()` | `STALE` | Значение может быть устаревшим |
| `Ошибка()` | `ERROR` | Значение получено в результате ошибки |

## Применение

Сравнение причины в прикладном коде:

```bsl
Детали = Клиент.ПолучитьСтрокуСДеталями("тема", "light", Контекст);

Если Детали.Причина = OpenFeatureReason.Выключено() Тогда
	Журнал.Информация("Флаг темы выключен, используем оформление по умолчанию");
КонецЕсли;
```

Заполнение причины в своём провайдере:

```bsl
Функция ВычислитьСтроку(Знач Ключ, Знач ЗначениеПоУмолчанию, Знач Контекст) Экспорт

	Возврат Новый ResolutionDetails(Значение, OpenFeatureReason.СовпадениеТаргетинга(), "вариант-а");

КонецФункции
```

Причина `DISABLED` - не ошибка: `ЭтоОшибка()` вернёт `Ложь`, потому что код ошибки не заполнен. Ошибку определяют
по `КодОшибки`, а не по причине.
