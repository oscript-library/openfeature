# Модуль `OpenFeature`

Глобальный экземпляр API, как того требует спецификация. Приложение настраивает провайдера один раз при старте,
а дальше везде работает с клиентом.

```bsl
#Использовать openfeature
```

## Методы

| Метод | Возвращает | Назначение |
|---|---|---|
| [`УстановитьПровайдер`](#установитьпровайдер) | - | Регистрация провайдера |
| [`Провайдер`](#провайдер) | `Произвольный` | Текущий провайдер |
| [`МетаданныеПровайдера`](#метаданныепровайдера) | `Структура` | Метаданные провайдера |
| [`СостояниеПровайдера`](#состояниепровайдера) | `Строка` | Состояние провайдера |
| [`ПолучитьКлиента`](#получитьклиента) | `FeatureClient` | Клиент оценки |
| [`ДобавитьХук`](#добавитьхук) | - | Хук для всех клиентов |
| [`УстановитьГлобальныйКонтекст`](#установитьглобальныйконтекст) | - | Контекст уровня приложения |
| [`ГлобальныйКонтекст`](#глобальныйконтекст) | `EvaluationContext` | Текущий глобальный контекст |
| [`Завершить`](#завершить) | - | Сброс всего состояния API |
| [`СоздатьИзолированныйЭкземпляр`](#создатьизолированныйэкземпляр) | `OpenFeatureApi` | Независимый экземпляр API |

## УстановитьПровайдер

```bsl
Процедура УстановитьПровайдер(Знач Провайдер) Экспорт
```

Регистрирует провайдера: инициализирует нового и завершает предыдущего. Провайдер, не сумевший подняться, сообщит
об этом своим состоянием: падать на старте приложения из-за флагов нельзя. Провайдер `Неопределено` даёт исключение.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Провайдер` | `Произвольный` | Объект, реализующий контракт провайдера |

Контракт провайдера: `Метаданные`, `Инициализировать`, `Завершить`, `Состояние`, `ВычислитьЛогическое`,
`ВычислитьСтроку`, `ВычислитьЧисло`, `ВычислитьОбъект`.

```bsl
OpenFeature.УстановитьПровайдер(Новый JsonFileProvider("флаги.json"));

Если OpenFeature.СостояниеПровайдера() <> "READY" Тогда
	Журнал.Предупреждение("Флаги недоступны, работаем на значениях по умолчанию");
КонецЕсли;
```

## Провайдер

```bsl
Функция Провайдер() Экспорт
```

**Возвращаемое значение**: `Произвольный` - текущий провайдер. До регистрации это
[`NoopProvider`](../Классы/NoopProvider.md).

```bsl
OpenFeature.Провайдер().Перечитать();  // если провайдер это умеет
```

## МетаданныеПровайдера

```bsl
Функция МетаданныеПровайдера() Экспорт
```

**Возвращаемое значение**: `Структура` - метаданные с полем `Имя`. Провайдер, у которого метаданные получить
не удалось, отдаёт имя `Неизвестный`, а не исключение.

```bsl
Сообщить(OpenFeature.МетаданныеПровайдера().Имя);  // JsonFileProvider
```

## СостояниеПровайдера

```bsl
Функция СостояниеПровайдера() Экспорт
```

**Возвращаемое значение**: `Строка` - `NOT_READY`, `READY`, `ERROR`, `STALE` или `FATAL`. Провайдер, не ответивший
на запрос состояния, считается в `ERROR`.

```bsl
Сообщить(OpenFeature.СостояниеПровайдера());
```

## ПолучитьКлиента

```bsl
Функция ПолучитьКлиента(Знач Домен = "") Экспорт
```

Создаёт клиента оценки. Не выбрасывает исключений даже без провайдера.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Домен` | `Строка` | Имя домена, попадает в метаданные клиента и видно хукам |

**Возвращаемое значение**: [`FeatureClient`](../Классы/FeatureClient.md) - новый клиент.

```bsl
Клиент = OpenFeature.ПолучитьКлиента("магазин");
```

## ДобавитьХук

```bsl
Процедура ДобавитьХук(Знач Хук) Экспорт
```

Добавляет хук, выполняемый при каждой оценке любого клиента.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Хук` | `Произвольный` | Объект с методами `До`, `После`, `ПриОшибке`, `Финально` (любой из них может отсутствовать) |

```bsl
OpenFeature.ДобавитьХук(Новый ХукМетрик());
```

## УстановитьГлобальныйКонтекст

```bsl
Процедура УстановитьГлобальныйКонтекст(Знач Контекст) Экспорт
```

Устанавливает контекст оценки уровня приложения. Он объединяется с контекстом вызова, причём контекст вызова имеет
приоритет. `Неопределено` сбрасывает контекст в пустой.

**Параметры**

| Параметр | Тип | Описание |
|---|---|---|
| `Контекст` | [`EvaluationContext`](../Классы/EvaluationContext.md) | Глобальный контекст |

```bsl
OpenFeature.УстановитьГлобальныйКонтекст(
	Новый EvaluationContext("", Новый Структура("окружение,версия", "prod", "1.4.0")));
```

## ГлобальныйКонтекст

```bsl
Функция ГлобальныйКонтекст() Экспорт
```

**Возвращаемое значение**: [`EvaluationContext`](../Классы/EvaluationContext.md) - глобальный контекст оценки.

```bsl
Сообщить(OpenFeature.ГлобальныйКонтекст().Получить("окружение"));
```

## Завершить

```bsl
Процедура Завершить() Экспорт
```

Завершает провайдера и сбрасывает всё состояние API: хуки, контекст, провайдера. После вызова снова действует
провайдер-заглушка.

```bsl
OpenFeature.Завершить();

Сообщить(OpenFeature.МетаданныеПровайдера().Имя);  // NoopProvider
```

## СоздатьИзолированныйЭкземпляр

```bsl
Функция СоздатьИзолированныйЭкземпляр() Экспорт
```

Создаёт независимый экземпляр API со своим провайдером, хуками и контекстом. Нужен там, где глобальное состояние
мешает: прежде всего в тестах и когда в одном процессе живут несколько несвязанных приложений.

**Возвращаемое значение**: [`OpenFeatureApi`](../Классы/OpenFeatureApi.md) - изолированный экземпляр API.

```bsl
Экземпляр = OpenFeature.СоздатьИзолированныйЭкземпляр();
Экземпляр.УстановитьПровайдер(Новый InMemoryProvider(Флаги));

Клиент = Экземпляр.ПолучитьКлиента();
```
